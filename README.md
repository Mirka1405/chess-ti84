# Chess board for TI-84 CE
Just a board with ability to move pieces.

Currently no move checking, check or checkmate checking. This is just supposed to be for when you don't have a board at hand in school.

Controls:
- enter - select a tile, and then move the selected piece to the other tile
- up,down,left,right - move cursor
- clear - exit without saving; next launch will be a clean slate
- del - exit and save board state; will be loaded on next launch
- 1-6 - add a white piece to the board; promotion is not implemented so use this instead
- 9 - toggle piece color
- 0 - remove piece
- f3 - flip all pieces
- f4 - flip black pieces
- f5 - flip the whole board
